# 纸间 · 墨水屏工作台

直接用 Chrome 或 Edge 打开本目录的 `index.html`，无需安装依赖、编译或联网。请保留同目录的 `app.js`、`style.css`、`bitmap-fonts.js`。字体资源来自原项目的日历字体，来源见 `FONT-SOURCE.txt`。

也可以在此目录执行 `python3 -m http.server 8765 --bind 127.0.0.1`，然后访问 `http://127.0.0.1:8765`。本次工作目录中的服务已启动。

## 使用

1. 选择今日清单、三件要事、时间安排或任务看板；切换模式会载入对应示例。
2. 修改标题、副标题、底部提示，以及每项任务的文字、状态和时间。
3. 选择原生日历点阵字体或系统字体。点阵字体使用 12/16px，或原生 12px 整数放大到 24px；系统字体支持 12—24px。可切换阈值、误差扩散或有序抖动，并调整墨色浓度。
4. 点击 1:1 查看 400×300 个 CSS 像素，或适宽 / 放大查看。屏幕的物理尺寸和浏览器显示尺寸不同。
5. 导出 PNG 交给 `epd-control` 上传；导出 JSON 保留可编辑内容和显示设置。编辑内容自动保存在当前浏览器，切换浏览器或网页地址不会共享这份记录。

清单与时间表最多显示 5 项，三件要事最多 3 项，看板最多 6 项；每栏通常最多 3 项，大字号时最多 2 项。最多可编辑 8 项，超过版面容量时会明确提示并阻止 PNG 导出。文字超宽或缺少字形也会提示，请调整后导出。

JSON 保存完整编辑器状态，`tasks` 中的任务格式如下；也支持导入旧模板的 `rows` 字符串数组：

```json
{
  "mode": "list",
  "title": "hsc · 今日任务",
  "subtitle": "今天",
  "footer": "先完成重要的事。",
  "tasks": [
    {"text": "提交项目进度", "time": "11:00", "status": "紧急"}
  ],
  "font": "bitmap",
  "size": 16,
  "method": "threshold",
  "threshold": 140,
  "red": true
}
```

模式值为 `list`、`focus`、`timeline`、`board`。状态为“待办”“进行中”“紧急”“待确认”“完成”。导出的 PNG 为 RGB 黑白红三色、400×300，预览和导出使用同一份像素。网页本身不会连接蓝牙或刷新屏幕。

这是一种像素预览，不能模拟墨水屏的残影、温度影响、实际色彩和刷新过程。所有初始任务与日期均为示例。

## 验证

使用真实 Chrome 检查了四种模板的调色板、编辑与增删、字体和抖动切换、黑白模式、溢出拦截、JSON 导入、本地保存以及手机页面宽度。四张 `*-example.png` 是从网页画布直接保存的示例。没有编译项目，也没有刷新实体屏幕。

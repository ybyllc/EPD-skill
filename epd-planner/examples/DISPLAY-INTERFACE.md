# 任务显示接口

消息端 AI 负责理解老板消息、维护任务与状态；显示端只接收完整看板 JSON、渲染图片并按需上传。无需再次理解原始聊天消息。

## 输入

参考 `task-template.json`，UTF-8 JSON 对象：

| 字段 | 类型 | 用途 |
| --- | --- | --- |
| title | 单行字符串 | 看板标题 |
| subtitle | 单行字符串 | 日期或任务来源 |
| rows | 字符串数组，最多 5 项 | 已按优先级排列的任务摘要，可包含状态与截止时间 |
| footer | 单行字符串 | 实际更新时间或提示 |

每次传入完整看板，替换上一版，不是增量追加。任务状态也用文字传入，例如“待办”“进行中”“待确认”。左侧方框目前是视觉装饰，不具有点击或勾选功能。

消息端保留完整任务；看板优先放紧急和临期事项。超过 5 项时，应明确选择要展示的任务，并可在页脚标明“另有 N 项”，不要无提示遗漏。没有截止时间或状态时不要编造。日期和更新时间应由消息端提供真实值，模板中的日期只是示例。

正文可用宽度 327 像素，18px 字体，大约可放 18 个全角字，实际以排版检查为准；标题、副标题、页脚也应简短。超长会报错，应缩短摘要，原文保留在消息端。

## 本机调用

只生成预览：

```sh
"$PYTHON" \
  "$SKILL_DIR/scripts/render_card.py" \
  task-template.json --output task-preview.png
```

收到显示指令后上传：

```sh
"$PYTHON" \
  "$SKILL_DIR/scripts/upload_epd.py" \
  task-preview.png --name NRF_EPD_A571
```

这是本机命令行接口，不是 HTTP 服务。其他 AI 可以通过本机执行工具调用，或把 JSON 交给本机 AI 执行。脚本失败返回非零状态；渲染失败时不得上传旧图片，使用成功生成的文件。对同一设备串行上传。

可以交给消息端 AI 的指令：

> 把当前任务整理成 epd-planner 支持的 title、subtitle、rows、footer JSON。每次输出完整看板，最多展示 5 项，优先显示紧急和临期事项。用简短文字保留状态和截止时间，不编造信息。需要更新屏幕时调用本机渲染脚本，成功后再调用上传脚本。
